# Tanaz Beauty

Luxury beauty studio website built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Run locally
1. Install Node.js 20+.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000

## Customize
Replace the placeholder phone, address, Instagram URL, prices and stock images in `app/page.tsx`.
